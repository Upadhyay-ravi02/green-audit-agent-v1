# Green Audit Agent v1 🌿

This is an autonomous AI agent designed to automate sustainability audits. It uses LLMs to navigate and verify carbon projects in a simulated environment.

## 🚀 Live Demo
The project is hosted and running on [Hugging Face Spaces](PASTE_YOUR_HF_LINK_HERE).

## 🛠️ Features
- **Autonomous Navigation:** Decision making via Qwen-2.5/Llama-3 models.
- **Environment:** Built on BrowserGym and OpenEnv frameworks.
- **Dockerized:** Fully containerized for easy deployment.

## 📂 Project Structure
- `inference.py`: The main agentic loop logic.
- `Dockerfile`: Configuration for containerized execution.
- `requirements.txt`: Necessary libraries for the AI environment.
